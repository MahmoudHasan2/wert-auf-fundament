# Offene Punkte vor dem Livegang – Wert auf Fundament GmbH

Die Website ist technisch fertig. Folgende Angaben und Freigaben müssen **vom Unternehmen** geliefert bzw. bestätigt werden. Alle Punkte erscheinen auch in der Checkliste auf der Übersichtsseite der Verwaltung.

## Pflichtangaben Impressum (Unternehmenseinstellungen)
- [ ] Vertretungsberechtigte Geschäftsführer (Namen)
- [ ] Registergericht und Handelsregisternummer (HRB)
- [ ] Ggf. Verantwortlicher nach § 18 Abs. 2 MStV (nur bei redaktionellen Inhalten, z. B. News)
- [ ] Ggf. weitere Pflichtangaben (z. B. Eintragung in die Handwerksrolle / zuständige Kammer)
- [ ] Aussage zur Verbraucherstreitbeilegung bestätigen

## Datenschutzerklärung (Entwurf – fachlich prüfen lassen)
- [ ] Hosting-Anbieter, Serverstandort, Abschluss des Auftragsverarbeitungsvertrags (AVV)
- [ ] Speicherdauer der Server-Logfiles (laut Hosting-Anbieter)
- [ ] E-Mail-Anbieter
- [ ] Datenschutzbeauftragter: benannt? (sonst Abschnitt löschen)
- [ ] Aufbewahrungsfrist für Kontaktanfragen (Einstellung, Standard 365 Tage)
- [ ] Anschrift der Aufsichtsbehörde kontrollieren
- [ ] Alle Markierungen „[BITTE PRÜFEN …]“ entfernen, Hinweisblock „Entwurf“ löschen

## Inhaltliche Freigaben
- [ ] **Rohbau:** Aussage „eigene Krane“ (Block ist ausgeblendet) – bestätigen, Anzahl/Typen ergänzen, dann einblenden
- [ ] **Garten- und Landschaftsbau:** alle aufgeführten Unterleistungen freigeben; Pflegeleistungen (ausgeblendet) nur bei Angebot einblenden
- [ ] **Baugrundverbesserung:** angebotene Verfahren bestätigen
- [ ] **Abbruch und Altlastensanierung:** Leistungsumfang, Sachkunde (z. B. TRGS 519/524), Zulassungen bzw. Kooperationspartner bestätigen
- [ ] **Unternehmen:** Kennzahlen (Gründungsjahr, Mitarbeitende) nur mit belegten Werten befüllen und einblenden
- [ ] Bürozeiten, Social-Media-Profile (optional)

## Bilder
- [ ] 24 Platzhalterfotos (Wikimedia Commons, CC BY-SA u. a., Urheber und Lizenz je Bild in der Mediathek) durch eigene Fotos ersetzen. Solange sie verwendet werden, muss „Bildnachweise anzeigen“ aktiv bleiben.
- [ ] Logo: verwendet wird das gelieferte Logo (zugeschnitten auf Bildmarke + Schriftzug). Für beste Qualität möglichst eine Vektor- oder hochauflösende PNG-Datei mit transparentem Hintergrund liefern.

## Referenzen
- [ ] Nur reale, zur Veröffentlichung freigegebene Projekte eintragen (Ort nur mit Zustimmung des Auftraggebers).

## Technik / Zugangsdaten
- [ ] SMTP-Postfach für Benachrichtigungen einrichten (README Abschnitt 5)
- [ ] SSL aktivieren, `app.url` auf https umstellen
- [ ] `install.token` nach der Installation aus env.php entfernen
- [ ] Indexierung erst nach Abschluss aller Punkte aktivieren
